    Scripting for FPGA Tools

    A script for Xilinx Tools

    Amd/Xilinx tools when installed drop the path environment settings in front of all other paths as most of the installed software does these days. To counter this and create an easy way to update environment settings use below script.

    • Add following to the .bash_aliases file and save it afterwards

      # Source a script that sets environments for Xilinx FPGA tools
. .XilinxFpgaEnv.sh
      - The script places all Xilinx environment settings at the end of the Linux path and makes it afterwards easy to update the path when a new software version is installed (only need to change the version of the software and evything runs smooth again). - Start a text editor (Xed, Gedit, Code, ..), and create a new text file. Name it .SetXlnxEnv.sh or give it another name, but make the name understandable. - Drop below text in the open text file and save it afterwards. - Text for the script:

      # Xilinx Tools
export XILINX_VERSION=2024.2
#
#export XILINX_CMAKE=cmake-3.24.2
#export PATH=$PATH:$XILINX_VITIS/tps/lnx64/$XILINX_CMAKE/bin:
#export LD_LIBRARY_PATH=/opt/Xilinx/Vitis/$XILINX_VERSION/tps/lnx64/$XILINX_CMAKE/libs/ubuntu
#
export XILINX_VIVADO=/opt/Xilinx/Vivado/$XILINX_VERSION
export XILINX_HLS=/opt/Xilinx/Vitis_HLS/$XILINX_VERSION
export XILINX_VITIS=/opt/Xilinx/Vitis/$XILINX_VERSION
export XILINX_DOCNAV=/opt/Xilinx/DocNav
#
export PATH=$PATH:$XILINX_VIVADO/bin
#export RDI_DATADIR=$XILINX_VIVADO/data
export PATH=$PATH:$XILINX_HLS/bin
export PATH=$PATH:$XILINX_VITIS/bin
export PATH=$PATH:$XILINX_DOCNAV
#
# Vitis specifics
#export PATH=$PATH:$XILINX_VITIS/gnu/microblaze/lin/bin:
#export PATH=$PATH:$XILINX_VITIS/gnu/microblaze/linux_toolchain/lin64_le/bin
#export PATH=$PATH:$XILINX_VITIS/gnu/aarch32/lin/gcc-arm-linux-gnueabi/bin
#export PATH=$PATH:$XILINX_VITIS/gnu/aarch32/lin/gcc-arm-none-eabi/bin
#export PATH=$PATH:$XILINX_VITIS/gnu/aarch64/lin/aarch64-linux/bin
#export PATH=$PATH:$XILINX_VITIS/gnu/aarch64/lin/aarch64-none/bin
#export PATH=$PATH:$XILINX_VITIS/gnu/armr5/lin/gcc-arm-none-eabi/bin
#export PATH=$PATH:$XILINX_VITIS/gnu/riscv/lin/riscv64-unknown-elf/bin
#
# Petalinux
. /opt/Xilinx/Petalinux/$XILINX_VERSION/tool/settings.sh
echo " Petalinux settings done. "
echo " Vivado is started by typing: vivado & "
echo " Vitis is started by typing: vitis & "
echo " DocNav is started by typing: docnav & "
sleep 1

    • The only thing here that keeps forcing its path in front of the system path environment is the sourcing of the Petalinux settings.sh script. It is going to be necessary to alter that script and possible scripts it sources. Another solutions of course is to copy the Petalinux script contents into this custom script.

    • Lets change the Petalinux settings.sh script.

    • Open with a text editor the \<path_to_Petalinux>/\<version>/tool/settings.sh script file.

    • Change in the file all text lines (8) starting with PATH=

    • The lines look like: PATH="${XSCT_TOOLCHAIN}\/Path_to_PetalinuxTool:${PATH}"

    • Change the lines to: PATH="${PATH}:${XSCT_TOOLCHAIN}\/Path_to_PetalinuxTool"

    • The settings.sh script sources another script .environment-setup-x86_64-Petalinux-linux

    • Here also, change the text line starting with export PATH=

    • Put \(PATH: in front of the Petalinux path and remove the :\)PATH from the end of the text line.

    A script for Efinix

    The Efinix path settings are placed in front of all other path settings, as most of the software installed on a Linux system now-a-days, blocking in this case the system installed or under pyenv running Python development tools. Therefore a small script is created and sourced from the bash_aliases file. The script asks if the user want to use, or not, the Efinix tools.

    • Add following to the .bash_aliases file and save it afterwards

      # Source a script that sets environments for Efinix FPGA tools
. .EfinixFpgaEnv.sh

    • Start a text editor (Xed, Gedit, Code, ..), and create a new text file. Name it .SetEfnxEnv.sh or give it another name, but make the name understandable.

    • Drop below text in the open text file and save it afterwards.

    • Text for the script:

      #!/bin/bash
#
# Arrive here from .bash_aliases to decide if the Efinix tools  
# environment variables are going to be set.
########################################################
#
AskQuestion () {
    read -p " Use Efinix FPGA tools or No tools at all? (E/N) : " Answr
    if [ "${Answr,,}" == "e" ]; then
        EnvsFor=Efnx
    elif [ "${Answr,,}" == "n" ]; then
        EnvsFor=Quit
    else
        echo " Probably entered wrong answer! "
        AskQuestion
    fi
}
#
SetEfnxEnvs () {
    # Efinity FPGA
    export EFINITY_VERSION=2024.2
    export EFINITY_HOME=/opt/Efinix/efinity/$EFINITY_VERSION/
    export PATH=$PATH:EFINITY_HOME/bin
    . /opt/Efinix/efinity/$EFINITY_VERSION/bin/setup.sh
    . /opt/Efinix/efinity-riscv-ide-$EFINITY_VERSION/setup.sh
    echo " Efinix Efinity tool is started by typing: efinity & "
    echo " Efinityy-RISC-V tool is started by typing: efinity-riscv-ide & "
    sleep 1
}
#
SetNone () {
    echo " No FPGA environments are set. "
}
#
#================================================================================
# Start/run the script to create a new project or library
#================================================================================
echo " Set the environment variables for the Efinix FPGA tools "
echo " or do not set any FPGA tool variables at all. "
#
sleep 1
AskQuestion
if [ "$EnvsFor" = "Efnx" ]; then
    SetEfnxEnvs
elif [ "$EnvsFor" = "Quit" ]; then
    SetNone
else
    AskQuestion 
fi
#
# The end

    A script for Efinix and Xilinx

    • When both Efinix and Xilinx FPGA tools are installed make use of a sourced script in the bash_aliases file.

    • Add with a text editor following lines in the .bash_aliases file

      # Source a script that sets environments following the used FPGA technology.
# The script asks if Xilinx or Efinix FPGA are going to be used and set the
# required environment variables accordingly.
. .SelectFpgaEnv.sh

    • Start a text editor (Xed, Gedit, Code, ..), and create a new text file and name it .SelectFpgaEnv.sh or give it another name, but make the name understandable.

    • Drop below text in the open text file and save it afterwards.

    • Text for the script:

      #!/bin/bash
#
# Arrive here from .bash_aliases to make a selection on what 
# FPGA tools to set the environments for. This approach has been 
# taken because the Efinix tools are taking over the default 
# Python environment and that can not be tolerated.
#
########################################################
#
AskQuestion () {
    read -p " Use FPGA tools for Xilinx, Efinix or No tools at all? (X/E/N) : " Answr
    if [ "${Answr,,}" == "x" ]; then
        EnvsFor=Xlnx
    elif [ "${Answr,,}" == "e" ]; then
        EnvsFor=Efnx
    elif [ "${Answr,,}" == "n" ]; then
        EnvsFor=Quit
    else
        echo " Probably entered wrong answer! "
        AskQuestion
    fi
}
#
SetXlnxEnvs () {
    # Xilinx Tools
    export XILINX_VERSION=2024.1
    #
    export XILINX_VIVADO=/opt/Xilinx/Vivado/$XILINX_VERSION
    export XILINX_HLS=/opt/Xilinx/Vitis_HLS/$XILINX_VERSION
    export XILINX_VITIS=/opt/Xilinx/Vitis/$XILINX_VERSION
    export XILINX_DOCNAV=/opt/Xilinx/DocNav
    #
    export PATH=$PATH:$XILINX_VIVADO/bin
    export PATH=$PATH:$XILINX_HLS/bin
    export PATH=$PATH:$XILINX_VITIS/bin
    export PATH=$PATH:$XILINX_DOCNAV
    #
    # Petalinux
    . /opt/Xilinx/Petalinux/$XILINX_VERSION/tool/settings.sh
    echo " Vivado is started by typing: vivado & "
    echo " Vitis is started by typing: vitis & "
    echo " Petalinux settings done. "
    sleep 1
}
#
SetEfnxEnvs () {
    # Efinity FPGA
    export EFINITY_VERSION=2024.1
    export EFINITY_VERSION=2024.1
    export EFINITY_HOME=/opt/Efinix/efinity/$EFINITY_VERSION/
    export PATH=$PATH:EFINITY_HOME/bin
    . /opt/Efinix/efinity/$EFINITY_VERSION/bin/setup.sh
    . /opt/Efinix/efinity-riscv-ide-$EFINITY_VERSION/setup.sh
    echo " Efinix Efinity tool is started by typingh: efinity & "
    echo " Efinityy-RISC-V tool is started by typing: efinity-riscv-ide & "S
    sleep 1
}
#
SetNone () {
    echo " No FPGA environments are set. "
}
#=========================================================================================
# Start/run the script to create a new project or library
#=========================================================================================
echo " Set the environment variables for the Xilinx FPGA tools "
echo " or set the environment variables for the Efinix FPGA tools "
echo " or do not set any FPGA tool variables at all. "
#
sleep 1
AskQuestion
if [ "$EnvsFor" = "Xlnx" ]; then
    SetXlnxEnvs
elif [ "$EnvsFor" = "Efnx" ]; then

    • When a command terminal is started, it will ask if Xilinx or Efinix or no tools are going to be used. Answer X, E or N (not case sensitive).

    Bash scripting hint

    For some time now I'm using two functions pathadd and pathrm that assist in adding elements to the path without the need to worry about duplications or front/end path issues.

    • pathadd takes a single path argument and an optional argument which if supplied will append the new path to the system PATH otherwise it prepends it.
    • pathrm removes a path from teh system PATH

    In almost every situation adding to the path will likely override anything already in the path, which is why I opt to prepend by default.

    pathadd() {
    newelement=${1%/}
    if [ -d "$1" ] && ! echo $PATH | grep -E -q "(^|:)$newelement($|:)" ; then
        if [ "$2" = "after" ] ; then
            PATH="$PATH:$newelement"
        else
            PATH="$newelement:$PATH"
        fi
    fi
}

    pathrm() {
    PATH="$(echo $PATH | sed -e "s;\(^\|:\)${1%/}\(:\|\$\);\1\2;g" -e 's;^:\|:$;;g' -e 's;::;:;g')"
}

    Use pathadd and/or pathrm in any script were the PATH environment is going to be altered. Like this example

    pathadd "/foo/bar"
pathadd "/baz/bat" after
export PATH

    There is now a guarantee to not add the new path to the existing path if it's already there. To ensure /baz/bat is at the start do:

    pathrm "/baz/bat"
pathadd "/baz/bat"
export PATH

    Any path can be moved to the front if it's already in the path without doubling.
